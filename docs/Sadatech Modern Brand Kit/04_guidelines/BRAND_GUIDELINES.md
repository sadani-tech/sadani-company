# SADATECH — Brand Identity Concept v1.0
**Direction:** Option B — Sculpted Modern  
**Source:** the selected Option B concept, plus the existing Sadani website ZIP.  
**Status:** proposed visual identity, not a registered trademark or confirmation of legal entity.

## 01. Brand essence
**Sadatech** is a technology-building brand focused on real problems, useful solutions, and considered execution. A modern engineering mindset with human-centered outcomes.  
**Core belief:** Good technology earns trust by making complexity useful.  
**Positioning:** Technology studio for practical digital products, bespoke software, integrations and automation.  
**Signature line (retained):** *Imagine. Build. Make It Real.*  
**Communication tone:** confident, human, clear, deliberate; avoid exaggeration and unverified achievements.

## 02. Logo concept
The primary symbol is an elegant, bold, two-part sculpture derived from the chosen Option B design:
- **Upper charcoal arc:** exploration, momentum and technological vision.
- **Lower gold bridge:** structure, useful building blocks, and tangible outcomes.
- **Open interior / forward direction:** clarity, progress, connection.

Use the **2D vector as the official primary logo**. The metallic 3D asset is an expressive brand illustration for hero banners, video and key visuals; do **not** use 3D art for tiny UI sizes.

## 03. Logo system
- **Primary horizontal:** `01_logo/sadatech-logo-horizontal-primary.svg` — light surfaces and website header.
- **Reverse horizontal:** `01_logo/sadatech-logo-horizontal-light.svg` — dark surfaces.
- **Stacked:** `01_logo/sadatech-logo-stacked-primary.svg` — portrait/signage.
- **Symbol only:** `01_logo/sadatech-symbol-primary.svg` — avatar, favicon, app icon.
- **Monochrome:** only when production constraints require single ink.
- **3D hero:** `01_logo/sadatech-logo-3d.webp` — isolated PNG/WebP from selected concept.

**Clear space:** preserve at least 15% of symbol height on all sides.  
**Minimum size:** standalone mark 24 px; horizontal lockup 140 px. Test at actual device resolution.  
**Don't:** stretch, rotate arbitrarily, apply extreme gold gradients to tiny icons, put the primary on similarly colored backgrounds, use a 3D render where a 2D vector is needed, or redraw the logo in each asset.

## 04. Color palette
| Name | Hex | Role |
|---|---|---|
| Near Black | `#161719` | premium dark backgrounds / hero |
| Charcoal | `#28282D` | primary shape and headlines |
| Champagne Gold | `#C99D4B` | gold section and accents |
| Light Gold | `#E2B763` | lighter accents on dark surfaces |
| Ivory | `#FFF9F0` | warm brand background |
| Satin Silver | `#A4A6A9` | **3D material/reference** and supporting UI |

Gold is an **accent**, not a body-text color on ivory. Ensure interface contrast using charcoal/near-black for readable copy. Color values are derived/normalized from the selected concept rather than asserting a pre-existing official spec.

## 05. Typography
The existing website uses **Montserrat** (300–700); retain it for consistency. Use Montserrat SemiBold/Bold for statements, Medium for headings and Regular for body. The supplied SVG wordmark is **outlined vector lettering**, so it does not require the font to be installed. This traced mark uses a clean Inter Display-based outlined wordmark while retaining Montserrat as the UI type system.

## 06. 3D art direction
**Material:** soft brushed silver above, satin champagne gold below; not mirror chrome, not overly yellow.  
**Light:** large, diffused key light from top-left; narrow rim highlight; subtle dark contact areas; restrained reflections.  
**Background:** warm ivory or deep charcoal. Avoid sharp clipping, gritty texture, exaggerated glow and blown-out highlights.

The included 3D image has been extracted from the selected Option B presentation artwork. It is **a transparent raster asset**, not a Blender/FBX/GLB model. `sadatech-logo-3d-2x.webp` is a scaled variant, **not** a newly rendered high-resolution 3D model.

## 07. Visual language and applications
- Layout: ample whitespace, deliberate modular grid, strong headline hierarchy.
- Graphic motifs: large curved ribbons, negative-space portals, subtle arcs.
- Photography/illustration: real product work, thoughtful interfaces, close details of engineering; avoid generic hacker imagery.
- Motion: slow, purposeful reveals and a subtle hero tilt only; respect reduced-motion preferences.
- Social avatars use symbol-only; website navigation uses the 2D lockup; hero uses 3D.

## 08. Content integrity
When publishing, use **Sadatech** as the public-facing brand. Do not automatically assert an incorporated `PT Sadatech` unless incorporation has been confirmed. Portfolio items shown on the former site should be clearly designated as internal products/experiments where relevant, not client commissions or live launches without evidence.
